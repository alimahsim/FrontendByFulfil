Label

The label element is used to define a label for an input element. It can be associated with a specific input by using the for attribute, which should match the id of the input.

Label Attributes

  • for
  • name

Input

The input element is used to create various types of form controls, such as text fields, checkboxes, radio buttons, and more. The type attribute specifies the type of input control to display.

Input Attributes

  • type
  • name
  • value
  • placeholder
  • required
  • readonly
  • disabled

Input types

  • text
  • password
  • email
  • number
  • checkbox
  • radio
  • file
  • date
  • color
  • submit

Button

The button element is used to create a clickable button. It can be used to submit a form or perform other actions

Button Attributes

Button specific attributes

  • name

  • disabled
  • hidden

  • class
  • style

  • tabindex

Button Types

  • submit

Select

The select element is used to create a drop-down list. It contains option elements that define the available choices.

Select Attributes

  • name
  • multiple
  • size
  • disabled

Textarea

The textarea element is used to create a multi-line text input field.

Textarea Attributes

  • rows
  • cols
  • maxlength
  • placeholder
  • required
  • readonly
  • disabled
